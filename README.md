## 🎨 2. Hệ Thống Thiết Kế & Design System

### 💎 iOS 26 Liquid Glass Architecture
- **Mặt kính phân tầng sáng (Specular Gradient):** Bề mặt thẻ sử dụng dải gradient từ trắng 84% ở phía trên xuống 60% ở phía dưới, giúp phần đầu thẻ đặc hơn để đọc chữ rõ ràng, phần đáy trong trẻo để thẩm thấu hậu cảnh.
- **Khúc xạ & Chiết suất ánh sáng:** Dải highlight mỏng dọc mép trên (`glass-specular`), kết hợp bán kính mờ nền `22px blur` và độ bão hòa màu nền `175% saturate`.
- **Bóng đổ đa tầng (Warm Ambient Shadow):** Khử hoàn toàn bóng xám cứng truyền thống, thay bằng quầng bóng ấm tỏa rộng, tạo cảm giác card đang lơ lửng trên không gian.

### 🌸 5-Season Dynamic Theme Engine
Hệ thống chuyển đổi giao diện thời gian thực với 5 bảng màu chủ đề:
1. **🌸 Xuân (Spring):** Tông hồng hoa anh đào pastel thanh khiết (`#ec4899`).
2. **🌿 Hạ (Summer):** Tông xanh lá ngọc bích tươi mát (`#10b981`).
3. **🍂 Thu (Autumn):** Tông cam mật ong ấm áp và hoài niệm (`#f59e0b`).
4. **❄️ Đông (Winter):** Tông xanh lam băng tuyết tĩnh lặng (`#3b82f6`).
5. **🌙 Đêm (Night / Obsidian):** Tông tím thạch anh huyền bí trên nền Onyx Obsidian (`#8b5cf6`).

> **Pha màu theo mùa (Season Card Tint):** Tự động pha `8%` màu của mùa đang chọn vào thẻ kính (`--season-card-tint`), đổi mùa thì sắc độ thẻ chuyển hóa mượt mà theo.

```
portfolio/
├── index.html              # Trang chủ: Bento Grid, Project Showcase, Skills & Experience
├── project.html            # Case Study Viewer đa năng (?id=1, ?id=2, ?id=3, ?id=7)
├── public/                 # Static assets (images, favicon, media)
│   ├── images/
│   │   ├── invitation/     # 01-09 hình ảnh chi tiết dự án Thiệp Mời Tốt Nghiệp
│   │   ├── tram-dien-xanh/ # Ảnh quy trình EV Smart Charging
│   │   ├── soundly/        # Ảnh màn hình Music Streaming
│   │   └── meowlish/       # Ảnh nghiên cứu người dùng & wireframes
├── src/
│   ├── index.css           # Design Tokens, Glass Specular & Season Variables
│   ├── script.js           # Core interaction logic, Season Theme Switcher, URL params
│   ├── three-background.js # Hiệu ứng hạt động không gian Three.js theo mùa
│   └── three-effects.js    # Shaders & hiệu ứng tương tác nâng cao
├── package.json            # Vite 6, Tailwind CSS v4, Three.js, Lucide
└── README.md               # Tài liệu dự án chuẩn hóa
```

### 💻 Công Nghệ Cốt Lõi:
- **Build Tool:** [Vite 6](https://vitejs.dev/) — Multi-Page Application (MPA) tối ưu hóa Rollup output.
- **Typography:** Google Fonts (`Plus Jakarta Sans`, `Outfit`, `Charm`, `Caveat`).
- **Icons:** [Lucide Icons](https://lucide.dev/) — Vector icon hệ thống đồng nhất.
- **Physics & Motion:** Three.js (Particle Canvas), Lenis (Smooth momentum scrolling).
- **Code Quality:** TypeScript type-check (`tsc --noEmit`), Tailwind CSS v4 engine.

## 🚀 5. Hướng Dẫn Vận Hành (Local Setup)

### Yêu cầu môi trường:
- Node.js >= 18.0.0
- Trình quản lý gói: npm / yarn / pnpm

### Các bước cài đặt:

```bash
# 1. Clone repository
git clone https://github.com/matthew28302/portfolio.git
cd portfolio

# 2. Cài đặt toàn bộ dependencies
npm install

# 3. Khởi động môi trường phát triển (Mặc định Port 3000)
npm run dev

# 4. Kiểm tra Type-check & Linting
npm run lint

# 5. Đóng gói Production sẵn sàng deploy
npm run build
```
